# CMS field notes: WordPress Playground

1. Posting and creating new page functions were simple and easy. All the commands were in sections in a small bar at the top, and adding anything to the page was in the same dropdown, making it quick and easy to learn the site.

2. They include notes that show which user created which sections of the website.

3. The "are you sure you're ready to publish" question that included visibility (public/private) and publishing date (available to set) was a strong feature.

4. The editor role page looks pretty much the same, it just doesn't have access to the users the same way admin does.

5. Project comments is a good feature as well, allowing for team and project updates and communications.

6. The dashboard should be easier to reach, maybe with a button on the page labeled (current site settings or <site name> settings or dashboard or something) as opposed to it being located in the site dropdown along with plugins and themes, which could be in their own section. The plugin and theme pages should each describe what they are and can do.

7. The slug for each page or post should be displayed somewhere, maybe in that title bar on top with the dropdowns. Slug should also be visible in the post viewer section.

8. I like the trash feature - deleted features go to the trash rather than being permanently deleted. I would have trash permanently deleted after 30 days, with a few notifications leading up to it so the user can set a custom delete date (or have it never delete) if they desire.

9. Make a suite of user types that the admin can create with different permissions, each described next to them, along with a custom option.
